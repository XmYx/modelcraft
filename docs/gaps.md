## Stability

### Undo budget is estimated, not measured
Scene-change entries count a flat ~300 bytes per object because meshes are shared; a scene with
thousands of imported meshes changed one by one may hold more than the 1 GiB budget suggests.
Measure shared allocations instead.

### Recovery replays `Import` by path
A crash journal that imports a file replays it from the same path. If the file moved, that command
fails during recovery and later steps on the imported object fail with it. Store imported meshes in
the journal (as a blob next to it) instead.

## File formats

### glTF has no quads
GLB export triangulates (glTF only stores triangles); importing our own GLB brings triangles back.
Add `EXT_mesh_quads`-style quad recovery or write quad hints in `extras` once craft-mesh keeps
`extras`.

### FBX, USD
craft-mesh reads FBX; not wired because FBX is proprietary and the suite prefers glTF. USD waits for
a scene-level reader in craft-libs (craft-usd has wire primitives only).

### `.gltf` (JSON) export
craft-mesh writes GLB only. Add a JSON writer to craft-mesh rather than here.

## Modeling

Bridge, fill hole, knife, booleans, retopology, edge creases, multi-segment bevel, loop/ring selection
commands, grow/shrink selection and spline-based generators (extrude, lathe, loft, sweep) are
missing. Bevel is one flat segment and skips boundary edges.

## UVs

UVs are generated by primitives and carried through edits (interpolated), but there is no UV editor,
unwrap, seam marking or packing. TextureCraft auto-unwraps meshes without UVs today.

## Sculpt

Missing: multiresolution levels, dynamic topology, even remesh, auto retopology, image stamps, layer
blending, hide/show by patch, brush presets. Pressure arrives through egui touch force; it is not
verified on every Wayland/X11/Windows tablet stack (the winit fork may need pen events).

## Paint

The Paint workspace shows patches and hands off to TextureCraft through GLB. Vertex colours,
texture painting and PBR channels are not implemented.

## Viewport

No snapping, no IBL or shadows, no matcap library, no camera bookmarks. Vertex points are drawn by
the UI painter and capped at 100 k.

## UI

Panels dock left/right/float/hide per workspace; no tabs, splits or saved layouts. Shortcuts are
fixed (no editor; craft-keymap is the intended path). The tree has no drag-and-drop reparenting
(the row menu does it). Properties edits only the active object.

## Agents

`modelcraft-cli control` speaks JSON lines on stdin/stdout; there is no socket listener, token
auth or MCP server yet (craft-control and craft-mcp-server exist in craft-libs).

## Performance

Evaluation, dabs and the BVH build are single-threaded. A 1 M-quad smooth cage takes about a second
to evaluate; sculpt session start on 1 M quads takes ~0.8 s.

## Animation

Not started: joints, skinning, keyframes, timeline, blend shapes.

## Release

The icon (a contributor draft) is rendered to every size; the Linux recipe (nfpm, desktop file,
metainfo, MIME) follows BoardCraft. macOS, Windows and Flatpak recipes and the launcher catalog entry
need the maintainers' signing setup and assets.
