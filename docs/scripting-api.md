# Scripting API reference

> Generated by `cargo xtask script-docs` from the function table in `crates/script/src/docs.rs` and the
> command registry in `crates/engine/src/command.rs`; do not edit it by hand. The language, the sandbox and
> the limits are in [scripting.md](scripting.md).

Scripts are [Rhai](https://rhai.rs). Ids are whole numbers; positions, scales and rotations are `[x, y, z]`
arrays (rotation as XYZ Euler degrees); a map is written `#{ key: value }`; `()` means "nothing". A function that
changes the scene runs a command, so it is journaled and undoable, and `undo_group` makes several one step.

## Commands

- `run(command) -> map`: Run a command given as a map with a "cmd" field, exactly the JSON the CLI and control channel take. Returns #{created: [ids], warnings: [text]}. The cmd:: functions below are the same thing with the name filled in.
- `undo_group(label, fn)`: Run `fn` and make everything it changes one undo step named `label`. If `fn` throws, its changes are rolled back and the error continues. Groups nest. undo and redo are not available inside one.

## Running commands

- `commands() -> array`: The command registry: an array of #{name, script_name, summary}.

## Objects

- `object_count() -> int`: How many objects the scene has.
- `object_ids() -> array`: Every object id in tree order (parents before children). Errors above the array limit: walk with roots() and children(id) instead.
- `roots() -> array`: The top-level object ids.
- `children(id) -> array`: The ids of an object's children, in order.
- `parent(id) -> id | ()`: The parent id, or () at the top level.
- `exists(id) -> bool`: Whether an object with this id exists.
- `find(name) -> id | ()`: The first object with exactly this name, in tree order.
- `find_all(pattern) -> array`: Ids of the objects whose name matches the pattern (`*` any run of characters, `?` one character; case matters), in tree order.
- `name_of(id) -> string`: The object's name.
- `kind_of(id) -> string`: "Mesh", "Group", "Smooth cage" or "Deformer".
- `object_info(id) -> map`: One map with id, name, kind, parent, children, visible, translation, rotation_euler, scale, material, steps (count), vertices and faces (of the evaluated mesh).
- `attributes(id) -> array`: The attribute names of this object: name, visible, translation, rotation_euler (degrees), scale, material, plus primitive, levels or deformer for those kinds.
- `get_attr(id, name) -> value`: Read an attribute. Vectors are [x, y, z]; material, primitive and deformer are maps.
- `set_attr(id, name, value)`: Set an attribute through its command (one undo step). A material, primitive or deformer map changes only the keys it names.

## Edit

- `add_primitive(kind) -> id`: Add a primitive: cube, plane, sphere, round_cube, cylinder, cone or torus.
- `add_primitive(kind, name) -> id`: Add a primitive with a name (made unique when taken).
- `add_group() -> id`: Add an empty group.
- `add_group(name) -> id`: Add an empty group with a name.
- `delete(ids)`: Delete an object (or an array of them) and its children.
- `duplicate(id) -> id`: Duplicate an object with its children; returns the new root.
- `rename(id, name)`: Rename an object.
- `reparent(id, parent)`: Move an object under another.
- `unparent(id)`: Move an object to the top level.
- `set_visible(id, visible)`: Show or hide an object.

## Transforms

- `get_translation(id) -> [x, y, z]`: The object's translation, in its parent's space.
- `get_rotation_euler(id) -> [x, y, z]`: The object's rotation as XYZ Euler angles in degrees.
- `get_scale(id) -> [x, y, z]`: The object's scale.
- `move_to(id, x, y, z)`: Set the translation.
- `move_by(id, dx, dy, dz)`: Add to the translation.
- `rotate_to(id, x, y, z)`: Set the rotation from XYZ Euler angles in degrees.
- `scale_to(id, x, y, z)`: Set the scale.
- `world_position(id) -> [x, y, z]`: Where the object's origin is in the world.
- `world_bounds(id) -> map | ()`: #{min, max} of the world-space box around the object and its children, or () when they have no geometry.

## Selection

- `selection() -> array`: The selected object ids.
- `set_selection(ids)`: Replace the selection with an id or an array of ids.
- `select(id)`: Add an object to the selection.
- `deselect(id)`: Remove an object from the selection.
- `clear_selection()`: Empty the selection.
- `is_selected(id) -> bool`: Whether an object is selected.

## Dependency graph

- `dependencies(id) -> array`: The objects whose values this object's evaluation reads: its visible deformer children (for a mesh), its first mesh child (for a smooth cage) and its parent (for its world transform).
- `dependents(id) -> array`: The objects that read this one: the inverse of dependencies.
- `graph_edges() -> array`: Every edge as #{from, to, kind} meaning `from` reads `to`; kind is "deformer", "input" or "transform".

## Evaluation

- `evaluate(id) -> Mesh`: The object's final evaluated mesh in its own space (history steps, deformers, smooth cage). Groups and deformers give an empty mesh. Cached, so repeated calls are cheap.
- `evaluate_step(id, index) -> Mesh`: The mesh after history step `index` (0 is the first), before deformers.
- `steps(id) -> array`: The object's history steps as #{index, name, enabled}.
- `evaluation_errors(id) -> array`: Steps that could not run, as #{step, message} (step is () for the object itself).

## Mesh

- `Mesh.vertex_count() -> int`: Number of vertices.
- `Mesh.face_count() -> int`: Number of faces.
- `Mesh.edge_count() -> int`: Number of edges.
- `Mesh.triangle_count() -> int`: Number of triangles after triangulating the faces.
- `Mesh.position(i) -> [x, y, z]`: One vertex position. Errors when i is outside 0..vertex_count.
- `Mesh.face(i) -> array`: The vertex numbers of face i, in order.
- `Mesh.face_normal(i) -> [x, y, z]`: Unit normal of face i.
- `Mesh.face_center(i) -> [x, y, z]`: Centre of face i.
- `Mesh.triangle(i) -> array`: The three vertex numbers of triangle i.
- `Mesh.bounds() -> map | ()`: #{min, max}, or () for an empty mesh.
- `Mesh.surface_area() -> float`: Total area.
- `Mesh.is_closed() -> bool`: True when every edge has two faces.
- `Mesh.volume() -> float`: Enclosed volume; errors unless the mesh is closed.
- `Mesh.stats() -> map`: #{vertices, faces, edges, triangles, closed, area, volume} (volume is () when open).
- `Mesh.positions() -> array`: Every position as [x, y, z]. Errors above the array limit; use positions_range.
- `Mesh.positions_range(start, count) -> array`: Positions start..start+count (cut at the end).
- `Mesh.faces() -> array`: Every face as an array of vertex numbers. Errors above the array limit; use faces_range.
- `Mesh.faces_range(start, count) -> array`: Faces start..start+count (cut at the end).
- `Mesh.indices() -> array`: Triangle indices, three per triangle, flat. Errors above the array limit.
- `Mesh.to_builder() -> MeshBuilder`: A copy of the geometry to change and build as a new object.

## Mesh builder

- `mesh_builder() -> MeshBuilder`: An empty builder.
- `MeshBuilder.vertex_count() -> int`: Vertices added so far.
- `MeshBuilder.face_count() -> int`: Faces added so far.
- `MeshBuilder.vertex(x, y, z) -> int`: Add a vertex; returns its number.
- `MeshBuilder.face(vertices) -> int`: Add a face from an array of vertex numbers (counter-clockwise seen from outside). The vertices must exist.
- `MeshBuilder.triangle(a, b, c) -> int`: Add a triangle.
- `MeshBuilder.quad(a, b, c, d) -> int`: Add a quad.
- `MeshBuilder.add_box(min, max)`: Add an axis-aligned box (8 vertices, 6 quads) between two [x, y, z] corners.
- `MeshBuilder.build(name) -> id`: Make a mesh object (the add_mesh command, one undo step).
- `MeshBuilder.build(name, parent) -> id`: Make a mesh object under a parent.

## Mesh positions

- `edit_positions(id) -> PositionEdit`: Copy the vertex positions of an object that stores its own mesh (made by build, an import, or collapse). Primitives: collapse them first.
- `PositionEdit.len() -> int`: Number of vertices.
- `PositionEdit.get(i) -> [x, y, z]`: One position; errors outside 0..len.
- `PositionEdit.set(i, x, y, z)`: Change one position; errors outside 0..len or for a non-finite value.
- `PositionEdit.translate_all(dx, dy, dz)`: Move every vertex.
- `PositionEdit.commit()`: Write the positions back (the set_positions command, one undo step).

## Files

- `read_text(path) -> string`: Read a UTF-8 text file inside a folder the run may read.
- `write_text(path, text)`: Write a text file atomically inside a folder the run may write.
- `file_exists(path) -> bool`: Whether a path inside a readable folder exists.
- `list_dir(path) -> array`: File names in a readable folder, sorted.
- `export_scene(path)`: Export the visible scene to .glb, .obj or .stl inside a writable folder.
- `script_dir() -> string`: The folder relative paths start from.
- `may_write_files() -> bool`: Whether this run may write anywhere.
- `make_dir(path)`: Create a folder (and its parents) inside a folder the run may write.

## Tools and callbacks

- `register_tool(label, fn)`: Add a command that runs `fn`; the app lists it in the Scripts menu. Registering the same label again replaces it; running the script again replaces everything it registered.
- `register_tool(label, tip, fn)`: The same with a tooltip.
- `tool_count() -> int`: How many tools are registered.
- `on_event(name, fn)`: Call `fn(event)` when an event happens (the app reports them once per frame). Names: scene_loaded, selection_changed, scene_changed, frame_changed. `event` is #{event, selection} or #{event, frame, skipped} where it has them.
- `on_scene_loaded(fn)`: Call `fn(event)` when a project is opened, imported or started new.
- `on_selection_changed(fn)`: Call `fn(event)` when the selection changes; `event.selection` is the new selection.
- `on_scene_changed(fn)`: Call `fn(event)` when anything in the scene changed, whoever changed it (callbacks do not trigger themselves).
- `on_frame_changed(fn)`: Call `fn(event)` when the current frame changed; `event.frame` is the new frame, and `event.skipped` how many frame changes were folded into it while the timeline played (0 otherwise).
- `clear_callbacks()`: Remove the callbacks this script registered.

## Arguments

- `args() -> map`: The `--arg name=value` pairs of the run, with values read as true/false, whole numbers, numbers or text.
- `arg(name, default) -> value`: One argument, or the default when it was not given.
- `current_file() -> string | ()`: The file name of the open project, or () when it has none.

## Math

- `round_to(x, digits) -> float`: Round a number to 0 to 12 decimal places.

## Random numbers

- `rng(seed) -> Rng`: A deterministic random generator: the same seed gives the same numbers on every machine.
- `Rng.next() -> float`: A number in [0, 1).
- `Rng.range(lo, hi) -> float`: A number in [lo, hi).
- `Rng.int_range(lo, hi) -> int`: A whole number from lo to hi, both included.

## Commands (`cmd::`)

Every command of the engine's registry is a function `cmd::<name>(map)` that takes the command's fields as a map
(`cmd::add_primitive(#{ kind: "cube", name: "A" })`), returns `#{ created: [ids], warnings: [text] }`, and is also
available as `run(#{ cmd: "<name>", ... })`. `import` is `cmd::import_file`, because `import` is a Rhai keyword. The
fields of each command are in [cli.md](cli.md#commands).

| Function | What it does |
|---|---|
| `cmd::add_primitive` | Add a parametric primitive: kind (cube, plane, sphere, round_cube, cylinder, cone, torus), name?, parent? |
| `cmd::add_group` | Add an empty group: name? |
| `cmd::add_smooth_cage` | Add a smooth cage generator around input? with levels |
| `cmd::add_array` | Add an array generator (linear, radial) around input?: real copies joined into one mesh |
| `cmd::add_symmetry` | Add a symmetry generator around input? mirrored across axis (0 X, 1 Y, 2 Z) |
| `cmd::add_deformer` | Add a deformer (bend, twist, taper, ripple, round, shear) under target |
| `cmd::add_cloner` | Add a clone generator (linear, radial, grid, scatter, surface, vertices) around input?; clones are instances of the input |
| `cmd::add_clone_modifier` | Add a clone modifier (plain, random, noise, step, delay, target) inside the clone generator cloner |
| `cmd::add_field` | Add a falloff field (sphere, box, linear, noise) inside the target deformer or clone modifier |
| `cmd::delete` | Delete objects and their children: ids |
| `cmd::duplicate` | Duplicate an object and its children: id |
| `cmd::rename` | Rename an object: id, name |
| `cmd::reparent` | Move an object under parent (null: top level) |
| `cmd::set_transform` | Set translation, rotation (quaternion x,y,z,w) and scale: id, transform |
| `cmd::set_visible` | Show or hide an object: id, visible |
| `cmd::set_material` | Set base_color, metallic, roughness: id, material |
| `cmd::set_primitive` | Change a primitive's parameters: id, primitive |
| `cmd::set_cage_levels` | Change a smooth cage's levels: id, levels |
| `cmd::set_deformer` | Change a deformer's parameters: id, deformer |
| `cmd::set_array` | Change an array's layout, copies and steps: id, array |
| `cmd::set_symmetry` | Change a symmetry's axis and join distance: id, axis, weld |
| `cmd::set_field` | Change a falloff field (shape, remap curve, invert, strength, blend): id, field |
| `cmd::set_clone_modifier` | Change a clone modifier (mode, strength, position, rotation, scale, tint) and its target object: id, modifier, target? |
| `cmd::set_cloner` | Change a clone generator's layout (mode, counts, offsets, seed) and target: id, cloner, target? |
| `cmd::add_step` | Append a history step (extrude, inset, bevel, loop_cut, merge, weld, delete_faces, delete_edges, delete_vertices, move_vertices, flip, triangulate, subdivide, set_patch, bridge, fill_hole, mirror, even_remesh, trim_plane {point, normal, cap}, decimate {ratio}): id, op |
| `cmd::set_step` | Change a history step: id, index, op |
| `cmd::enable_step` | Switch a history step on or off: id, index, enabled |
| `cmd::remove_step` | Remove a history step: id, index |
| `cmd::collapse` | Bake an object's history into its mesh: id |
| `cmd::set_locked` | Protect objects from edits or allow them again: ids, locked |
| `cmd::set_template` | Show objects for reference only (not picked in the viewport): ids, template |
| `cmd::add_selection_set` | Remember a selection: name, ids |
| `cmd::remove_selection_set` | Forget a selection set: index |
| `cmd::import_file` | Import a glTF, GLB, OBJ, STL, PLY, FBX or 3MF file: path, up? (auto, y, z), scale? (metres per file unit) |
| `cmd::begin_sculpt` | Start sculpting a mesh object: id |
| `cmd::end_sculpt` | Stop sculpting |
| `cmd::sculpt_stroke` | Apply a brush stroke: id, stroke {brush {…, live_detail?: edge length}, dabs} |
| `cmd::sculpt_mask` | Change the mask: id, op (clear, fill, invert, blur, sharpen, grow, shrink, hollows, ridges, occlusion, {patch: {triangle}}) |
| `cmd::sculpt_groups` | Make patches while sculpting: id, op ({by_normal: {angle}}, by_uv_island, by_part, from_mask) |
| `cmd::sculpt_visibility` | Hide and show faces while sculpting: id, op (show_all, invert, hide_masked, hide_unmasked, {hide_patch: {triangle}}, {show_patch: {triangle}}, {isolate: {triangle}}) |
| `cmd::sculpt_region` | Mask or hide inside a screen outline: id, region {view_proj (16 numbers, object to clip space), points [[x, y]…] in −1..1, front_only?, eye?}, action (mask, unmask, hide, isolate) |
| `cmd::sculpt_clip` | Move what lies on the normal's side of a plane onto it: id, point, normal |
| `cmd::sculpt_extract` | New object from the masked faces as a closed shell: id, thickness |
| `cmd::transfer_uvs` | Give a mesh the UVs of another by closest-point lookup, as a history step: id, source, max_distance?, per_island? |
| `cmd::sculpt_project` | Move the sculpted mesh onto the surface of another object, as far as the mask allows: id, source, reach? |
| `cmd::sculpt_detail` | Step up or down a detail level, keeping the sculpted detail: id, op (up, down) |
| `cmd::sculpt_shape` | Edit shape layers: id, op (add {name?}, remove {index}, merge {index}, strength {index, strength}, select {index or null}, rename {index, name}) |
| `cmd::add_mesh` | Add a mesh from raw geometry: positions [[x,y,z]…], faces [[i,j,k…]…], name?, parent? |
| `cmd::set_positions` | Replace the vertex positions of a stored mesh: id, positions [[x,y,z]…] |
| `cmd::batch` | Run several scene commands as one undo step, all or none: commands [{cmd…}…], label? |
| `cmd::undo` | Undo the last change |
| `cmd::redo` | Redo the last undone change |

## Example scripts

In `examples/scripts/`; each is run by a test in CI. Run one with `modelcraft-cli run-script`, passing arguments with `--arg`.

- `batch_export.rhai`: Batch export: writes every top-level object to its own file in a folder. Arguments: dir ("exports"), format ("glb", "obj" or "stl"). Needs permission to write files.
- `dependency_report.rhai`: Dependency report: lists what each object's evaluation reads, from the dependency graph.
- `distribute_selection.rhai`: Distribute: spaces the selected objects evenly along an axis, keeping the first and last where they are. Arguments: axis ("x", "y" or "z"; default "x").
- `mesh_stats.rhai`: Mesh stats: prints vertices, faces, triangles, area and volume of every mesh, then the totals.
- `rename_by_pattern.rhai`: Rename by pattern: gives every object whose name matches a pattern a numbered new name. Arguments: pattern ("*", where * is any run of characters), name ("Object_#", # becomes 01, 02, ...).
- `scatter.rhai`: Scatter: drops copies of a primitive at seeded random places on a square, all under one group. Arguments: count (40), area (10.0), seed (7), kind ("sphere"). The same seed gives the same scatter.
- `staircase.rhai`: Staircase: one mesh object for a straight staircase made of solid steps. Arguments: steps (12), rise (0.18), run (0.28), width (1.2).
